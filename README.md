# 🎮 Hangman Game
Classic Hangman game built with JavaScript to practice DOM and game logic

## 🚀 Features

- Random word selection  
- Letter guessing system  
- Wrong attempts counter  
- Win/Lose detection  
- Interactive UI  

## 🎯 How to Play

- Guess the word one letter at a time  
- Each wrong guess counts as an attempt  
- You win if you guess all letters correctly  
- You lose if you reach the maximum number of wrong attempts  

## 🛠 Technologies Used

- HTML  
- CSS  
- JavaScript(Vanilla)

## 📌 Project Goal

This project was built to practice JavaScript logic, DOM manipulation, and handling user interactions.
